# 用 CSS 做一台有呼吸感的终端界面

记录一次关于噪点、扫描线、边框和微妙动效的视觉实验，探索代码如何制造“正在运行”的感觉。

## 少量动效更像真实系统

如果每个元素都在动，界面很快会变成噪音。更好的方式是只给一个核心元素生命感，让周围的静态结构负责托住它。

```css
.signal-bar i {
  box-shadow: 0 0 12px var(--cyan);
}
```

光晕、边框和留白共同构成了终端的呼吸节奏。
